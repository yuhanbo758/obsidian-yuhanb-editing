# 功能对照与实现边界

本表以 [Enhanced-editing 的公开功能说明](https://github.com/obsidian-canzi/Enhanced-editing#readme) 为需求来源，对照本项目独立实现的命令和行为。

所有命令 ID 都带 `yuhanbo-editing:` 前缀，下表省略该共同前缀。标题 `Ctrl/Cmd+1～6` 以及 39 组参考键默认可用，已保存的参考键开关继续保留。Obsidian 自定义绑定优先，配置面板标注让出的默认键位。

## Enhanced-editing 0.5.2 键位核对

| 键位 | 操作与兼容方式 |
| --- | --- |
| `Alt+G` | 既有高亮命令补上默认键。 |
| `Alt+I/J/K/L/O` | 上、左、下、右、行尾移动。 |
| `Alt+Shift+U/N` | 按名称顺序循环打开同文件夹上一或下一 Markdown 笔记。 |
| `Alt+Shift+J/L` | 向上或向下跳转同类 Markdown 结构，或查找下一处同类格式、相同选文。 |
| `Ctrl/Cmd+反引号` | 清除当前行或选中行的 ATX 标题语法，保护代码和 YAML。 |
| `Ctrl/Cmd+Alt+Shift+D` | 先展开已有折叠，再折叠当前标题同级的标题，恢复原选区。 |
| `Ctrl/Cmd+Alt+Shift+Enter` | 在光标处插入全角空格和换行，使空行在渲染时可见。 |
| `F9` | 四则运算结果复制到剪贴板。普通选文显示字符数。 |
| `Alt+D` | 保持现有行内代码。0.5.2 的代码块可从命令面板执行或自定义绑定。 |
| `Alt+U` | 若已绑到其他自定义命令则让出。0.5.2 的「光标移至行首」可从命令面板执行或自定义绑定。 |
| 旧插件自定义键 | 由 Obsidian 按当前库的设置调用原命令。 |

0.5.2 源码中处于注释的同级页面滚动、独立格式刷组合和富文本粘贴没有作为默认键纳入。命令操作参考本机版本的行为，代码独立实现。

## 标题、格式与颜色

| 功能 | 本项目命令 ID | 实现与边界 |
| --- | --- | --- |
| 一级至六级标题 | `heading-1`～`heading-6` | 当前行或选中行切换，同级再次执行恢复正文。默认在焦点编辑器内优先使用 Windows/Linux `Ctrl+1～6`、Mac `Cmd+1～6`；可关闭优先键组改用宿主自定义绑定，不改写全局快捷键文件。 |
| 自动识别标题 | `auto-headings` | 已实现选文或全文的短行识别；默认二级，可在设置中改为一级至六级。句末标点、数字、符号及已识别结构行保留。采用规则识别，不做语义理解。 |
| 粗体、斜体、行内代码 | `bold`、`italic`、`inline-code` | 已实现添加与去除。行内代码根据内容中的反引号长度选择分隔符，避免吞并原代码。 |
| 删除线、高亮、注释 | `strike`、`highlight`、`comment` | 已实现 `~~`、`==`、`%%` 成对切换。 |
| 下划线、上下标 | `underline`、`superscript`、`subscript` | 已实现 `<u>`、`<sup>`、`<sub>` 包装，不附带独立排版或导出引擎。 |
| 代码块 | `code-block` | 已实现当前行或选中行的围栏切换，选择安全长度的反引号。取消已有代码块需包含完整首尾围栏；局部代码区域不会再次嵌套插入围栏。 |
| 待办状态 | `task-cycle` | 已实现普通行转待办，以及空白、`x`、`-`、`!`、`?`、`>`、`<`、`+` 状态循环。只改变 Markdown 状态字符，不附带任务调度器。 |
| 挖空 | `cloze` | 已实现 `{{c1::文字}}` 切换。此项只生成语法，不包括卡片复习、遮挡渲染或第三方记忆插件。 |
| 常见中文括号 | `bracket-square`、`bracket-round`、`bracket-quote`、`bracket-book` | 已实现 `【】`、`（）`、`「」`、`《》` 四种成对切换。 |
| 文字颜色、背景颜色 | `text-color-1`～`text-color-5`、`background-color-1`～`background-color-5` | 已实现各五个可配置槽位，使用经过校验的十六进制颜色与 HTML span；相同颜色再次执行去除，同类颜色可更换。 |
| 复制与应用格式 | `brush-copy`、`brush-apply`、`brush-once`、`brush-continuous`、`brush-stop` | 1.1.0 补齐状态栏激活的一次/连续格式刷。选择源文字后开启，再用鼠标划选正文目标自动应用，Esc 退出；支持标题、颜色和多层组合格式，并保留两步操作。格式只保留在当前实例内，禁用后清空。重复应用赋予样式，不切换去除。 |
| 无格式文本 | `strip-markdown`、`copy-plain-text` | 已实现移除可识别的 Markdown 格式并保留显示文字；复制命令写入剪贴板。代码中的实际内容保留，不承诺任意 Markdown/HTML 都能被无损转换。 |

## 链接、智能符号与导航

| 功能 | 本项目命令 ID | 实现与边界 |
| --- | --- | --- |
| 内部链接切换 | `wiki-link` | 已实现选文加/去 `[[...]]`，支持换行和顿号分隔的批量转换；无选区时可插入空链接，在已有链接内可去除外层。文件名中的非法字符会保守处理。 |
| 别名内部链接 | `wiki-alias` | 已实现生成 `[[\|显示文字]]`，由用户补入目标笔记名；去除已有别名链接保留显示文字。 |
| 批量链接已知笔记 | `link-known-notes` | 已实现匹配库内唯一、完整、不少于两个字符的笔记名，较长名称优先，保留已有链接/代码/网址。不会链接重名笔记，不使用模糊猜测、别名扩展或外部实体识别。 |
| 智能符号匹配与跳过 | `smart-symbol` | 已实现常见中英文括号、内部链接及粗体/高亮/删除线/注释等成对符号的补全和右符号跳过，以及部分连续符号替换。作用于无选区光标，保留正文光标位置。 |
| 语言缩写生成代码块 | `smart-symbol` | 已实现 `dv`、`qy`、`mm`、`js`、`ts`、`py`、`ph`、`css`、`c`、`java`、`json`、`sql`、`html`、`bash` 等缩写或支持的完整名称。只生成语法，不安装 Dataview、Mermaid 等执行组件。 |
| Callout 简写 | `smart-symbol` | 1.1.0 补齐中文类型名、原生别名、左中右/lcr/英文对齐、可紧邻的折叠符号和标题。支持 README 动图中的 `笔记 右+`、`摘要l-`、`提示 中-`、`问题r+`、`info c`。对齐使用本插件专属元数据与 CSS。 |
| 本地路径链接 | `path-link` | 已实现选中 Windows 或 POSIX 绝对路径与 `file:///` Markdown 链接之间转换，编码中文及部分 URL 特殊字符。只转换文字，不打开或读取库外目标。 |
| 当前笔记查找选文 | `find-selection` | 1.1.0 改为保留选文并调用公开 `MarkdownView.showSearch()` 打开宿主当前文档搜索面板，去除旧的插件替代弹窗。原生面板填词行为由宿主处理，尚待用户实机试用。 |
| 时间信息与视频跳转 | `seek-video` | 解析当前行时间，定位并调用播放。有明确笔记链接时只处理目标；唯一目标尚未打开时在侧边阅读视图打开并等待视频渲染。支持一个原生 HTML5 视频，多个目标或播放器拒绝猜测，iframe 不在范围内。异步等待后校验原笔记和选区，浏览器拒绝播放时提示手动播放。 |
| 选择整段、整句 | `select-paragraph`、`select-sentence` | 已实现以空行划分整段，以及当前行内以中文/常见句末标点划分整句。不进行跨行语义分句。 |
| 选文重命名当前笔记 | `rename-from-selection` | 已实现文件名校验、同名保护和确认窗口，确认后调用 Obsidian 文件管理 API。不会覆盖已有目标。 |
| 嵌入当前网址 | `embed-url` | 已实现将选中的无账号密码 HTTP/HTTPS URL 作为受限 iframe 插入行末。渲染时会访问网址；不绕过站点的嵌入限制或认证。 |
| 获取相对路径 | `copy-relative-path` | 已实现复制当前笔记在库内的相对路径到剪贴板；不复制本机库根目录。 |

## 中文、表格与正文整理

| 功能 | 本项目命令 ID/设置 | 实现与边界 |
| --- | --- | --- |
| 中英文标点转换 | `punctuation-zh`、`punctuation-en` | 已实现常见标点双向转换，保护可识别代码、链接、网址、HTML 与 Markdown 结构，保守保留小数等上下文。不处理所有语言的排版习惯。 |
| 简繁转换 | `to-traditional`、`to-simplified` | 已实现 OpenCC `cn↔t` 离线转换；词典已打包，运行时不联网、不调用 AI。不附带地区用语转换开关。 |
| Office/网页表格智能粘贴 | `smart-paste`、自动表格粘贴开关 | 已实现 HTML 单表、制表符文本转 Markdown。合并格保留左上角文字，其余位置使用空占位；不保留合并视觉效果。嵌套表格、多表、越界/重叠合并格会拒绝，避免静默丢失。 |
| 常见语法错误修复 | `fix-markdown` | 支持 `1。列表`、中文与混合全半角括号链接及 `[[]]()` 一类可识别错误。1.1.0 补齐相对路径、附件和锚点目标的括号修复；保留代码及正常链接，不转换危险协议。 |
| 合并意外断行 | `join-soft-lines` | 已实现合并同一正文段内、前行没有句末标点或显式硬换行的相邻行；保留空行、列表、标题、引用、表格与代码。 |
| 获取标注 | `extract-annotations` | 已实现提取标题、高亮、注释与 `#标注`、`#批注`、`#反思` 等前缀行，结果写入剪贴板，不自动创建新笔记。 |
| 回车额外空行 | “回车额外插入空行”设置 | 已实现，默认关闭；仅普通正文行末单光标生效，跳过输入法组合、重复键、修饰键、列表、引用、标题、表格、代码等情形。 |
| 批量添加/去除空行 | `blank-lines-add`、`blank-lines-remove` | 已实现选文或全文处理，保护代码和 YAML；添加空行时保留表格相邻行，避免拆散表格。 |
| 当前行上下插空行 | `blank-line-above`、`blank-line-below` | 已实现显式行插入。此类直接编辑命令按用户指定位置插入换行，不属于自动整理。 |
| 每行末尾双空格 | `hard-breaks` | 已实现选中行或无选文全文的 Markdown 硬换行处理，跳过受保护代码与元数据。 |
| 去除行尾空格 | `trim-trailing-spaces` | 已实现选中行或无选文全文处理，跳过受保护区域。去除双空格会同时去除对应 Markdown 硬换行。 |
| 中英文间距 | `chinese-spacing` | 已实现汉字与字母/数字之间添加空格，保护代码、链接等结构。 |
| 去正文空格 | `strip-spaces` | 已实现正文中的半角/全角空格去除，保留已识别的结构前缀、代码、网址、链接和标签。不是对原始文件的无条件全局空格删除。 |

## 入口、设置与安全行为

| 项目 | 当前行为 |
| --- | --- |
| 状态栏与命令入口 | 状态栏分组菜单、侧边图标、命令面板和编辑器右键入口。命令搜索使用 Obsidian 公开的模糊选择窗口 API。 |
| 设置与快捷键入口 | Obsidian 设置页及插件设置窗口。39 组参考键可逐项开关，选择会保存。自定义键优先，面板显示已让出的绑定。 |
| 多选区与撤销 | 合并重复编辑范围，使用编辑器事务提交批量改动，保持选区方向和文字相对光标位置；冲突或越界编辑整批取消。 |
| YAML/代码保护 | 行命令跳过受保护行；正文整理保留结构；行内格式、颜色和内链选区碰到 YAML/代码块时拒绝。只选中行内代码的局部正文时拒绝，避免丢失上下文。 |
| 异步粘贴保护 | 读取剪贴板后重新确认当前编辑器、文件、原文、选区和插件生命周期；任一变化则取消，避免把等待中的结果写到错误位置。 |
| 设置存储 | 使用当前库的标准插件数据存储；颜色、回车行为、自动表格与自动标题级别可持久保存。 |
| 平台 | manifest 最低版本 `1.14.4`，`isDesktopOnly: true`，面向 Windows/macOS/Linux 桌面；未声明移动端支持，实际平台验证另见记录。 |
| 运行时网络与账号 | 核心处理离线，无账号、API Key、付费服务、遥测、后台上传、自更新或运行时词典下载。主动插入并渲染网页 iframe 时由 Obsidian 浏览器访问用户所选网址。 |
| 剪贴板 | 只在主动智能粘贴命令读取、主动复制命令写入；自动表格开关开启后读取当前编辑器粘贴事件的数据。无后台剪贴板轮询。 |
| 库外文件 | 不直接读写库外目标；绝对路径命令仅转换链接文字。 |
| 发布 | 安装文件和构建证明见 [GitHub Releases](https://github.com/yuhanbo758/obsidian-yuhanb-editing/releases)。 |
